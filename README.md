# IndigoStudioCZ/.github

Organization-wide files of [Indigo Studio](https://indigostudio.cz).

| Path | What it is |
| --- | --- |
| `profile/README.md` | Profile shown on [github.com/IndigoStudioCZ](https://github.com/IndigoStudioCZ). GitHub shows it only while this repository is public. |
| `profile/banner-*.png` | Profile banner for the dark and light theme |
| `brand/avatar.png` | Organization avatar. GitHub has no API for it, upload it in Settings → Profile picture. |
| `brand/build.mjs` | Source of the banner and the avatar. `node brand/build.mjs` regenerates the SVG and PNG files (needs `rsvg-convert`, on macOS `brew install librsvg`). |

Colors, logo and doodles come from the [indigostudio.cz](https://indigostudio.cz) website.
